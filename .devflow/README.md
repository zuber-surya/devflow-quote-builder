# .devflow

This folder is the complete AI-managed project intelligence and workflow layer.

## Do not treat this as ordinary documentation

The AI maintains these files while working with the Human.

## Main areas

- `requirements/` — approved requirements
- `business/` — business understanding
- `decisions/` — approved decisions
- `questions/` — open questions
- `assumptions/` — tracked assumptions
- `constraints/` — project constraints
- `architecture/` — architecture knowledge
- `database/` — database knowledge
- `api/` — API knowledge
- `ui-ux/` — UI/UX knowledge
- `security/` — security knowledge
- `testing/` — test strategy/cases/traceability
- `artifacts/` — original inputs
- `changes/` — changes and impact analysis
- `state.md` — small current workflow state

Detailed knowledge is Markdown-first. Do not create duplicate JSON project-memory files.
